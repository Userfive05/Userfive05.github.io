# My Random Projects

The combined site lives in this folder. It uses the Project Journal layout and the original GitHub site's TwistAssist and Home Assistant Floorplan content and images.

Open index.html to preview. Upload this folder's contents to your GitHub Pages repository root to publish. No build tools or dependencies are needed. The original twistassist.html and hassfloorplan.html URLs are preserved.

- index.html: three-project gallery
- twistassist.html: cap opener story, photos, and Thingiverse download
- hassfloorplan.html: Home Assistant Floorplan work-in-progress page
- air-quality-monitor.html: ESPHome monitor build story and ten supplied photos; Thingiverse enclosure download and ESPHome YAML linked
- style.css: shared responsive layout
- theme.js: light/dark mode, with a saved browser preference
- images/: original supplied project images

Click a project photo on a detail page to view the full image. The floorplan page is a work-in-progress placeholder. Its previous images are retained in images/floorplan but are no longer displayed.

All illustrative sample projects and stock photographs have been removed. The supplied GitHub source folder is unchanged.
